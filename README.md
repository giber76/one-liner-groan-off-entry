Entry for [The One-Liner Groan-Off](https://make.fun/bounty/u-alfasurya91-the-one-liner-groan-off-5a1febd5)
on make.fun — a single original dad joke, one line of at most 140 characters.

## The joke (63 characters)

> I told the toaster it was toast. It said, "I'm bread for this."

## Why this line

- **Fast punchline:** the turn is the last four words — "I'm bread for this"
  (bread / bred: a toaster was literally made for toasting).
- **Fresh wordplay:** the setup is a put-down ("it was toast"), so the reply
  feels like the toaster talking back; the double meaning needs no explanation.
- **Tight and repeatable:** two short sentences, 63 characters, easy to say
  out loud at the dinner table and easy to pass on.
- **A proper groan:** silly enough to make people laugh, sharp enough to be
  worth repeating.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the joke to
`/output/entry.txt`.
